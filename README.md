# Wound Quantification Code

This repository contains the image analysis and quantification scripts used in the manuscript:

**Smad7-based biologic targeting epidermis and stroma promotes healing of diabetic wounds in mice and pigs**

**Authors:**  
Yao Ke, Ben-Zheng Li, Fulun Li, Resmi K. Ravindran, Donna Wang, Suyan Wang, Sam T. Hwang, Scott Simon, Sean R. Collins, Christian D. Young, Xiao-Jing Wang

**Preprint DOI:**  
https://doi.org/10.64898/2025.12.31.697220

---

## Overview

This codebase was developed to quantify wound healing dynamics from longitudinal wound images acquired from diabetic mouse model.
